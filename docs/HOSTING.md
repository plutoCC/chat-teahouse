# 邀请制网站：从自己的电脑分享茶馆

有两种使用方式：从 GitHub 下载后在自己电脑部署的人，自行提供 API Key；访问你提供的网站的人，使用你开放的模型和额度。AI 形象组成公共池，大家可邀请同一形象；群聊、消息、评论、笔记和模型私有会话仍按人类账号隔离。

默认最多 10 个有效邀请账号，可在分享助手调整，不提供公开注册。应用级隔离不是对站长加密：站长掌握服务器文件。访客的讨论会发送到站长选择的模型供应商。

## Windows 可视化管理

已有网站配置后，双击项目根目录的 **`Share-Teahouse.cmd`**，打开「茶馆分享助手」。可以给这个文件创建桌面快捷方式，脚本本身须留在项目目录。

1. 查看「网站」和「公网分享」的状态。重启电脑后，点击启动网站；若公网分享已关闭，再点击开启分享。
2. 点击打开网站或复制网址。朋友打开这个 HTTPS 地址后，用自己的访问码登录。
3. 在邀请区填写朋友的名字，创建邀请，再复制完整邀请内容私下发给本人。以后在列表中选择该朋友即可重新查看、复制访问码。访问码加密保存在本机，登录时仍用摘要校验；普通状态查询与账号列表不包含明文码。
4. 在列表中选择不再允许访问的人，点击撤销访问并确认。该账号的码和会话失效，原有记录保留；需要重新邀请时创建新账号。
5. 在「额度与限制」中设置全站和每人的人民币预算、模型调用次数、并发、群聊数量及成员数量等。保存后生效，不清零已有用量；降低限制不会删除历史或移除已有成员。
6. 临时不对外开放时，关闭公网分享；不再运行网站时，停止网站。关闭助手窗口不会停止网站或隧道。

每位朋友使用独立访问码；几个人共用同一码会共用同一工作区。模型配置从「本机模型设置」打开。助手不会自动登录 Tailscale、开通账户权限、修改防火墙或开启电脑自启。

旧版只保存访问码摘要，无法从摘要还原原码。仍有原码时，可在助手中补存，校验通过后加密保存；遗失时需明确确认重置。重置保留原账号、群聊、笔记和用量，让旧码及已登录会话失效。撤销与重置是不同操作。

首次使用须先完成下文的网站和隧道配置。助手沿用 `data-hosted/hosting-launch.json`；缺少配置、未安装 Tailscale 或该设备已有其他转发配置时会提示处理，不会覆盖其他服务。Tailscale 状态正常表示转发配置已开启，实际可达性仍取决于网络，分享前请在浏览器确认能打开。它是本机 Windows 窗口，没有额外 HTTP 管理端口；访客不能从网站调用这些操作。

## 没有服务器也能分享吗

可以。自己的电脑运行后端，通过支持 HTTPS 和 SSE 的隧道提供网址。无需租 VPS，但电脑必须开机、保持联网、运行程序及隧道；休眠、断网或停止程序都会中断网站。域名、隧道服务、模型 API 可能有各自费用，不保证零成本或全天在线。

推荐 **Cloudflare 命名隧道**：需要 Cloudflare 账号及托管在 Cloudflare 的域名，按 [官方设置说明](https://developers.cloudflare.com/tunnel/get-started/) 安装 `cloudflared` 并配置公网主机名到本机网站入口。它通过出站连接运行，无需在路由器上暴露个人应用端口。

没有自有域名时，可以使用 [Tailscale Funnel](https://tailscale.com/docs/features/tailscale-funnel) 提供的设备 `*.ts.net` HTTPS 地址。Funnel 面向公网，朋友无需安装 Tailscale；茶馆仍使用自己的邀请访问码。只希望组网内访问时，可选择 [Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve)。两种方式都只能转发网站登录网关，不能分享个人管理页面。

不要使用 `trycloudflare.com` 临时 Quick Tunnel 来验收本项目；[官方文档](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) 明确其不支持 SSE，本项目依靠 SSE 实时更新群聊。

GitHub Pages 只能发布静态文件，无法运行本项目的 Node 后端和 SQLite。以后迁到云服务器时可沿用此入口，但需要持久磁盘、进程管理、HTTPS 和备份；普通静态托管或短生命周期函数不能直接替代。

## 1. 安装与启动网站

先按 [部署指南](DEPLOYMENT.md) 安装 Node.js 24、获取源码，并执行 `npm ci`、`npm run build`。现有一键启动脚本依然启动个人模式；网站使用单独的命令。

以下域名均为占位示例，必须换成自己的专用 HTTPS 域名或 Tailscale 分配给设备的完整 HTTPS 地址，不带末尾斜杠。不能把示例地址当作已上线网址。

Windows PowerShell 后台启动（在项目目录执行）：

```powershell
.\scripts\start-hosted.ps1 -Action Start -Origin 'https://tea.example.com'
```

首次启动必须提供 `-Origin`。脚本会构建生产页面；已经执行过 `npm.cmd run build` 且代码未变时，可加 `-SkipBuild`。若 PowerShell 的脚本执行策略阻止运行，可在该次命令中使用 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-hosted.ps1`，后接相同参数。

脚本把公开来源、网站数据目录、端口和额度保存到 `data-hosted/hosting-launch.json`，日志位于 `data-hosted/service-logs/`，进程状态位于 `data-hosted/runtime/`。后续启动复用已保存配置，不覆盖它，也无需再次传入域名：

```powershell
.\scripts\start-hosted.ps1 -Action Status
.\scripts\start-hosted.ps1 -Action Stop
.\scripts\start-hosted.ps1 -Action Start
```

重复启动会检查现有服务，不另起一份进程。需要改变域名时，先停止网站，再编辑 `hosting-launch.json` 后启动。额度及产品限制使用分享助手修改，由 `hosting-settings.json` 保存，运行中读取最新设置；不要再改启动配置里的旧额度副本。配置文件不保存 API Key 或访问码；不要手动把凭据填进去。网站进程和 HTTPS 隧道分别启动、停止，脚本不会自动配置隧道。

macOS / Linux 前台启动：

```sh
CHAT_TEA_PUBLIC_ORIGIN=https://tea.example.com CHAT_TEA_HOST_DATA_DIR=./data-hosted npm run host
```

程序仍只监听本机回环地址：

| 入口 | 默认端口 | 用途 |
| --- | --- | --- |
| 原个人服务 | 4317 | 原有聊天及本地功能；可共享 AI 形象，私人历史不共享 |
| 网站站长管理 | 4318 | 仅本机管理网站模型连接和价格；不公开 |
| 网站登录网关 | 4319 | **唯一允许由隧道转发的入口** |
| 每用户后端 | 自动分配 | 仅由登录网关内部使用；不公开 |

网站使用 `data-hosted/`，不会迁入个人群聊和笔记。自定义网站目录也必须与个人目录分离，不能使用链接路径。根目录含账号/额度台账及公共形象库，`owner/` 保存站长模型配置，`users/<账号ID>/` 保存每人的独立数据。实际部署中的个人端与网站端接入同一个公共形象库，首次接入只导入形象资料及头像，不复制聊天、推理、日志、笔记或账号密钥。需要保留整个网站数据目录及其权限，不要纳入版本控制。

Windows 后台服务不依赖启动窗口，但脚本**没有安装开机自启服务或计划任务**，电脑重启后需重新执行 `Start`。`Stop` 会核对本脚本启动的进程身份，然后结束该进程；这会中断在途调用，已提交给供应商的请求可能仍计费，已有数据和额度预留会保留。建议先结束讨论再停止。前台 `npm run host` 使用 `Ctrl+C` 停止。个人模式的停止按钮/脚本不负责网站入口。

## 2. 站长配置开放的模型

在站长电脑打开 `http://127.0.0.1:4318/`，通过「模型连接」配置专用于网站的 API Key、默认模型、该模型的输入/输出单价，再启用连接。

在「向网站会员开放的模型」勾选一个或多个模型并保存连接，每个模型须分别配置输入和输出单价。全部取消可关闭共享；访客不能变更连接、价格或 Key，也看不到财务凭据。输入和输出价格均须大于 0。

网站提供已开放的云 API，不开放演示成员、站长的浏览器、Codex 订阅、Ollama 或本机工具。访客可以创建自己的角色、选择已开放模型、使用内置文字技能；不能安装新的技能。站长停用连接后，后续付费派发立即拒绝；已提交给供应商的请求可能已经计费。

ChatGPT 订阅只供其账号本人使用。[OpenAI 官方条款](https://openai.com/policies/sign-in-with-chatgpt-terms/) 不允许把一个人的订阅额度用于其他用户的请求。访客的成员列表隐藏订阅形象；需要 GPT 时由站长另行开放 OpenAI API 连接。不会自动切换到付费 API。

公共池共享名字、头像、身份提示词、模型选择和可共享的内置技能。创建者与站长可以管理形象，其他人可邀请或复制。群成员使用邀请时的快照；修改、删除公共形象不会改写其他人的既有群聊。自定义私有技能和本机专用连接不会随形象上传；访客列表隐藏不可用形象。形象名称及角色描述会对本站会员可见，请勿写入私人信息或密钥。

建议在供应商侧为网站建立单独的项目/Key 和用量上限。这是独立于程序估算的第二层费用保护。站长管理页面自己的测试或讨论不计入访客网站台账。

## 3. 邀请朋友与撤销

在另一个终端、项目目录中执行。若使用自定义目录，设置同一个 `CHAT_TEA_HOST_DATA_DIR`，或显式提供 `--data-dir`：

```sh
npm run host:user -- add "朋友A"
npm run host:user -- list
npm run host:user -- revoke "账号ID"
```

Windows 若受到 PowerShell 脚本策略限制，改用 `npm.cmd`。命令也可在网站未启动时使用。

新增时生成 256 位随机访问码，通过私人渠道交给对应朋友。访问码相当于登录凭据，可以重复用于登录，不是一次性链接；不要放入 URL、公开截图、README 或日志。数据库用于认证的字段仍是摘要；可重新查看的码独立加密保存，Windows 使用当前系统用户的 DPAPI 保护。朋友在网站登录页输入码后，Cookie 会话有效期为 7 天，默认每个账号最多同时 8 个登录会话、4 个实时页面，这两项可在助手调整。

撤销会使访问码和所有会话失效，已有 SSE 默认 10 秒内断开，后台讨论约 2 秒内开始取消。已经发往供应商的请求可能无法撤回计费。撤销保留旧数据，新增账号不会自动继承旧账号的群聊；换码应选择原账号的重置功能。

## 4. 连接 HTTPS 隧道

### 使用 Cloudflare 命名隧道

在 Cloudflare 创建正式命名隧道及专用主机名，源服务配置为 **`http://127.0.0.1:4319`**。`cloudflared` 与茶馆运行在同一台电脑。公网域名必须与 `CHAT_TEA_PUBLIC_ORIGIN` 完全一致。

- 保留公网域名的 HTTP Host，不要把源请求 Host 重写成 `localhost`。网关会验证 Host 和浏览器 Origin。
- 不创建到 4317、4318 或用户内部端口的路由，不给整个回环网段配置通配穿透。
- HTTPS 由隧道服务终止，浏览器端必须使用 HTTPS，登录 Cookie 不支持普通 HTTP 分享。
- SSE 不得缓存或缓冲，保留长连接；本项目已有 15 秒心跳。为该专用域名配置绕过缓存，不启用缓存所有内容。
- 推荐再使用 Cloudflare Access 邮箱白名单作为额外入口保护。若启用 Access，按 [官方自托管应用指南](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/) 配置应用策略及 Tunnel 的 Access Token 验证。本项目仍使用自己的访问码来绑定工作区，不信任请求里的邮箱身份头。
- 隧道 Token 属于秘密，按官方方式保存于本机，不写进仓库。本文不提供带真实 Token 的命令或自动修改你的网络。

### 使用 Tailscale Funnel（无需自有域名）

在站长电脑安装并登录 Tailscale，按 [官方要求](https://tailscale.com/docs/features/tailscale-funnel#requirements-and-limitations) 启用 MagicDNS、HTTPS 和 Funnel 权限。先在设备页面确认完整 DNS 名称，将对应的 HTTPS Origin 配置给茶馆，例如占位地址 `https://tea-host.example-tailnet.ts.net`。首次启用 Funnel 可能要求到浏览器完成授权。

先确认设备当前的 Funnel 配置，确保 HTTPS 443 可以专用于茶馆，再按 [当前 CLI 用法](https://tailscale.com/docs/reference/tailscale-cli/funnel) 开启后台转发：

```sh
tailscale funnel status
tailscale funnel --bg --https=443 http://127.0.0.1:4319
tailscale funnel status
```

Windows 若找不到 `tailscale` 命令，可把它替换为 `& 'C:\Program Files\Tailscale\tailscale.exe'`（或实际安装路径）。核对输出中的公网 HTTPS 地址与茶馆 `publicOrigin` 完全一致，且代理目标只有 **`http://127.0.0.1:4319`**。不要把 4317、4318、每用户内部端口或整个目录配置为公开目标；不使用原始 TCP 转发替代这里的 HTTPS 反向代理。

`--bg` 使 Funnel 在后台持续运行，并可在 Tailscale 重启后恢复；它不会让茶馆进程自动开机启动。仅停止本示例的 Funnel 转发时，使用对应的关闭命令：

```sh
tailscale funnel --bg --https=443 http://127.0.0.1:4319 off
```

Funnel 的 HTTPS 地址对公网开放，访问者仍须通过茶馆邀请登录。正式分享前应从外部网络验收登录、实时消息和撤销；本地 `Status` 正常只代表网站进程及回环端口正常，不代表公网隧道已经可用。

本机管理正常但网站返回“访问地址不正确”，应检查 Host 配置；“拒绝跨来源请求”应检查域名、协议及 `CHAT_TEA_PUBLIC_ORIGIN`。不要通过删除安全检查解决。

## 5. 服务端额度

以下环境变量用于首次初始化预算。后续优先使用本机分享助手保存的 `hosting-settings.json`，设置运行中生效，重启后保留；启动配置里的初始值不会覆盖已保存设置。`.env.example` 仅供参考，程序不会自动读取 `.env` 文件。

| 变量（均以 `CHAT_TEA_HOST_` 开头） | 默认值 | 含义 |
| --- | --- | --- |
| `DAILY_CNY` | 20 | 全部访客每日人民币估算额度 |
| `USER_DAILY_CNY` | 5 | 每位访客每日估算额度 |
| `MONTHLY_CNY` | 300 | 全部访客每月估算额度 |
| `USD_CNY` | 7 | 用于网站台账的估算汇率 |
| `DAILY_CALLS` | 200 | 全部访客每日调用次数 |
| `USER_DAILY_CALLS` | 50 | 每位访客每日调用次数 |
| `CONCURRENCY` | 4 | 全站同时付费请求上限 |
| `USER_CONCURRENCY` | 2 | 每位访客同时付费请求上限 |
| `MAX_OUTPUT_TOKENS` | 16384 | 网站单次最大输出，站长可修改 |

日期按 **UTC** 划分，每日 UTC 00:00（北京时间 08:00）重置日额度；跨日仍受月额度约束。访客能看到自己的当日费用估算、预留和调用次数，不能修改宿主上限；更改群预算、重开讨论、新建群或重启服务不能清零此台账。

分享助手另有可调整的账号数量、同时登录会话/实时页面、每人群聊/公共形象数量、每群 AI 人数/消息条数、同时讨论群数/思考成员数，以及群设置中可填的轮次、调用、预算和单次唤醒上限。它们是所有会员统一使用的站点规则，群内仍可设置更小的本场预算。修改不会删除超出新限制的已有内容；新的创建、启动、请求和保存按新规则检查。不同页面同时编辑会提示版本冲突，防止旧窗口覆盖新设置。报文校验、认证、来源检查及防滥用速率限制仍保留，供应商自身的模型与额度限制也不能由此解除。

派发前以请求字节量加协议余量保守预留输入，加上允许的最大输出，按当前模型分别的输入/输出单价计算费用。返回后按实际 Token 结算；失败且确定未生成则释放金额但仍计一次调用，网络中断/未知用量/服务崩溃保留预留。因此“额度不足”可能表示**无法预留下一次请求**，不表示供应商账号已欠费。金额是估算保护，不能保证与缓存、阶梯、附加计费或供应商最终账单完全一致。

达到并发或额度限制时停止本次模型调用，用户稍后继续。无效访问码的失败响应与有效账号的登录分别限流；无效码刷屏不会占用有效账号的登录额度，不同有效账号也分别计数。普通请求及 SSE 也有限制，避免一个用户耗尽全部连接。此方案没有大规模公开站点所需的分布式队列、DDoS 防御和计费系统。

## 6. 上下文压缩的实际范围

长期群聊使用全群共用的公共摘要。在「群聊设置 → 讨论设置 → 公共上下文摘要」中选择独立连接和模型，它不必属于任何成员；按正常模型选择器读取官方候选列表。未选择时，短对话照常运行，需要压缩才会提示设置，不擅自选择收费模型。可保存为新群默认模板。

- 只把公开消息的正文、作者、消息编号、引用和公开表情标签发给摘要工具；不发送成员人设、私有草稿、推理日志、笔记或技能。摘要要求保持中立、注明观点归属与分歧，不参与讨论、不调用工具、不作为群消息发表；模型摘要仍可能有偏差和遗漏。
- 未读历史或成员私有请求约达 160KB 时触发。全群同一段公开记录只生成一次，并发成员等待共用；长记录仍需分批。近期优先保留 20 条完整公开消息，过大时调整到完整发言边界。小量新增记录先保留原文，累计后再更新摘要。
- 请求投影用公共摘要与近期公开原文代替较早完整私有会话。系统身份、近期完整私有会话及工具配对保留；更早私有草稿和旧思考仍在本地原始 JSONL 中，但不承诺继续携带全部私有细节。当前未完成的巨大消息/异常工具配对仍可能触发 240KB 安全保护。
- 输出预算使用群单次输出设置（含推理消耗），摘要正文保持精简。公共摘要单次超时默认 600 秒，在群设置中可改为 10～3600 秒。普通成员请求的超时不因该设置改变。超时/失败保留原文和已完成进度，不自动重试；手动继续可接着整理。
- 用量与费用以「公共摘要」工具身份单列，使用所选模型的输入/输出单价，仍计入本场 Token、调用次数、金额和网站额度。每次唤醒最多整理 3 批，已经完成的部分不重复计费。本机订阅可用于摘要并消耗订阅额度；网站只允许站长开放的云模型。按轮模式不使用此压缩。
- `public-summary-memory.json` 保存受校验的群级摘要和分批进度（最多 64 项），隔离不同群、账号、连接及模型；原文修改会使旧缓存失效。原始聊天、笔记和成员私有 JSONL 不被删除。旧 `context-memory.json` 仍保留，但不会当成公共摘要共享。

本场预算到达后，可点击「续开讨论（保留上下文）」重开本场预算，沿用成员私有会话、摘要和已读位置；累计用量、供应商额度与网站日/月额度均不清零。「重新开始」仍会重置成员上下文。自主讨论不限制持续时间，旧版保存的截止时间不再生效；调用次数、Token、金额及网站额度保护保留。点击暂停会让已开始的整组连发按原阅读节奏发完，再暂停；排队和推理中的其他回复停止。输入草稿保护仍生效，关闭服务或权限失效则立即停止。

## 7. 上线验收与维护

本地自动化测试使用虚构账号、模型响应和独立目录。它们覆盖身份伪造、账号隔离、笔记/图片/群聊、CSRF、禁用管理接口、撤销和额度台账，但不能替代真实隧道的网络验收。

正式分享前，用两个测试邀请在不同浏览器登录：确认互相看不到群聊/笔记，访客没有管理入口，模型列表只有你开放的模型，实时消息能够更新，撤销后连接断开，再检查费用上限。先用演示成员验收，有意测试付费模型时使用小额度。

维护时先停止整个网站，再备份完整 `data-hosted/`，包含账号与额度台账、所有用户目录和站长凭据；不能只备份其中一个数据库。更换电脑涉及 Windows DPAPI 的凭据不可移植问题，按 [备份指南](DEPLOYMENT.md#备份与恢复) 重新配置密钥。定期更新 Node/依赖，操作系统休眠和升级也应纳入停机安排。
