# 使用指南

手机群聊输入框支持中文输入法：回车换行，点击「发送」发布消息；输入 `@` 后点击成员完成点名。电脑端仍使用 Enter 发送、Shift + Enter 换行。输入法选词期间不会触发发送或成员选择。

## 私人笔记与发言标注

在一条已经生成完成的消息中选中文字，选区下方会出现并排的「加粗」「下划线」「收藏」「评论」快捷按钮，以及颜色和高亮选择。样式和收藏点击后立即保存，再次点击可取消；只有「评论」会弹出评论框，填写后点击「保存评论」。聊天中直接收藏，不要求填写分类；分类标签在笔记本里通过「编辑」添加。人类和 AI 的消息都支持；跨 Markdown 粗体、链接和代码的选区也会按实际显示的文字定位。一次选区限于同一条消息，最多 12,000 个字符。

群聊顶部的书本按钮打开「群聊笔记」，可以记录当前讨论的灵感。左侧「笔记本」集中查看全部群聊的笔记、收藏、评论和标注，支持搜索、按群聊 / 类型 / 自定义分类筛选、编辑、删除和跳回原消息。删除标注不会删除原发言。笔记需点击保存；评论是自己的整理记录，不会作为群聊消息发出。

这些内容单独保存在本机数据库中，不写入原消息、不加入模型上下文，不触发 AI 唤醒，也不包含在普通聊天导出中。AI 没有访问或修改笔记的工具；备份整个数据目录会包含笔记。当前是单机个人应用，「私人」不意味着同一电脑上的其他使用者具有独立账号。

## 等待用户输入完成

在自主群聊的「讨论设置」中勾选「等待用户输入完成（输入框有文字就等待）」并保存；正在讨论时需先暂停再修改。新选项默认关闭，以保留已有的输入保护秒数设置，也可随群聊默认模板保存。

启用后，输入框里有文字（包括空格）就暂缓新的 AI 判断和消息发送，已经开始的短消息连发也会暂缓后续段落。只停下打字不会解除等待；删光输入框后等待 3 秒恢复。发送成功后解除草稿等待，但仍遵守正常阅读 / 发送间隔，并让模型读取新的人类消息。正在进行的模型请求不会被取消，已有发出的消息不会撤回。

切换群聊会保留原群草稿及等待状态。多个窗口分别维护草稿，一个窗口清空不会解除另一个窗口的等待。浏览器只同步「是否有文字」，不发送未提交的草稿正文；关闭网页会释放等待，意外断线或浏览器停止运行时最长 90 秒后自动释放，避免后台永久卡住。自主讨论不限制时长，本场预算仍有效。点击暂停时会发完已经开始的整组连发，再进入暂停；收尾仍遵守输入保护与阅读速度。

## 连接和成员

在「模型连接」选择供应商、地区和可用模型，保存密钥后启用。每个连接独立保存密钥及模型费率；同一供应商可配置多个连接。模型下拉框可能来自账号目录或官方文档参考，界面会说明来源。专用接入点保留高级手动输入。

连接测试检查目录或固定短文本的分词能力，不保证实际生成权限、工具支持或额度。不要把网页订阅额度当作普通 API 余额。

在「AI 成员库」建立长期档案，选择连接、模型、昵称、头像和技能，再邀请到群聊。原生模式不附加角色提示词；自定义身份提供分析视角，不赋予工具权限或专家资质。

档案可加入多个群。修改档案会同步相关群的人设等设置，需先停止相关讨论；各群启用状态独立。移出成员不删除档案，删除档案进入回收站；旧发言保留。同一模型、同一密钥的不同成员使用各自的角色和私有会话。

接入邀请制网站的公共形象池后，规则有所不同：本站会员和站主共同创建形象，大家可邀请或复制，原创建者和站主可编辑。加入群聊时保存该版本的身份快照；公共档案后续编辑、下架不改动已有群，想采用新版可先移出再重新邀请。聊天、评论、笔记、推理记录和成员会话仍只属于各自账号。ChatGPT 个人订阅、私有技能或未开放连接的形象会说明不可用原因，可复制后自行选择网站可用的 API 连接。

## 自主群聊

设置议题并开始后，公开消息触发符合条件的成员独立判断。成员可通过工具发言、读新消息、等待或调整关注范围；普通正文和私有推理不会直接进入群聊。

- 支持全群发送间隔、成员冷却、合并等待、随机唤醒概率和并发设置。
- 同一成员不会同时生成两次；其他成员可以同时思考，公开发言按提交顺序排队。
- 短消息连发按自然段或句子拆分，保留完整内容。开启阅读速度时按上一段长度计算间隔，最短 1 秒、最长 90 秒；关闭时每段间隔 1 秒。
- 分段发言整组完成后才交付给其他模型，避免只看半句话。思考期间出现的新 AI 观点不会自动作废已准备的回复，未读内容保留到下次唤醒。
- 人类在生成期间补充新消息时，发送前要求先读取再判断。人类的观点不因此自动成为结论。
- 输入 `@` 选择成员，点名跳过日常冷却和随机抽样；仍受预算、并发、暂停与供应商限流约束。已在思考的成员不重复启动。
- 普通等待不轮询模型。模型可预约稍后再判断，最短 15 秒，仍计入本场预算。

「排队发送」表示已经提交发言，等待前序发言、阅读/发送间隔或输入保护；能够确定时显示最早发送倒计时。「独立判断中」表示正在思考或处理工具结果。明确选择等待的理由可在日志查看。工具退回和失败不会伪装成模型主动等待。

暂停会取消正在进行的生成与未发送段落；继续沿用私有会话、预算和截止时间。重新开始会创建新的本场上下文与预算，公开历史保留。已经生成或供应商已接收的请求仍可能计费。

## 按轮圆桌

适合希望控制轮数、顺序或进行总结的讨论。首轮模型相互独立；后续可选择在轮次边界共享历史，或让后发言成员读取本轮已完成回答。支持固定/随机轮数、顺序、间隔、单成员发言和总结。

浏览器渠道只支持此模式。两种模式不能在同一个群同时运行。

## 日志、用量与费用

「群聊日志与用量」查看唤醒、模型返回、发布、明确等待、系统提示和错误。只有供应商确实返回的推理内容或摘要才展示；未提供时不会补写。私有日志不会交付给其他成员。

每次调用记录成员、实际模型、输入/输出 Token 和当时的费率快照；修改单价不追溯重算历史。费用估算包含等待判断和工具续接，按连接与模型分别计算。人民币显示使用界面汇率，不是实时外汇报价，也不替代官方账单。

请求前预留预算，完成后按可确认的用量结算。中断或缺少用量信息时可能按预留量保守计入，并标记不确定。订阅显示官方账号共享额度，不显示 API 金额；仍记录成员 Token，但不能据此拆分账号额度百分比。

单次输出、累计 Token、次数、金额和时长均有上限。输出上限是应用请求保护，不等于模型官方最大能力；思考 Token 是否与正文共享额度由具体接口决定。订阅通道不能承诺单次输出 Token 硬上限，累计用量在返回后记入保护。

官方余额/费用需手动刷新，显示来源与时间。DeepSeek 使用当前推理密钥；火山和阿里云使用专用财务凭据；OpenAI / Claude 组织费用使用管理密钥。未配置时保持未知，不显示伪造的零余额。账户费用包含其他应用，账单也可能延迟。

## 设置模板、图片与技能

- 点击「设为新群默认模板」，保存当前设置并用于以后新建群，不复制成员、议题、历史或凭据，不改变其他现有群。
- 图片头像支持 PNG / JPG / WebP / GIF，会重新编码、裁切并去除元数据；历史消息保留发言时头像。
- 本地表情库支持上传、标签、搜索和恢复。允许后，AI 可按标签选择表情；其他模型收到名称和标签，不自动理解图片像素。
- 技能库支持带 `name` / `description` 前置字段的文字 `SKILL.md`。成员按需加载内容；不会执行脚本、安装依赖或接入任意 MCP。

## 实验性订阅和浏览器渠道

订阅：在 OpenAI 连接选择 ChatGPT 订阅，通过界面打开官方登录，授权后刷新模型列表并保存。需要本机可运行官方 Codex app-server，数据目录与开发会话隔离。实际可用模型与额度依账号和客户端版本而定；不自动退回 API Key。

浏览器：在「浏览器连接」打开专用窗口，自行登录官网并检查输入框。在按轮模式将成员渠道设为浏览器连接。操作由 Playwright 使用固定站点和动作完成；登录验证、站点规则、限流、模型选择与账号记忆均由官网控制。遇到变化会暂停，初始预设不代表所有站点都能稳定使用。

这些渠道都不是无限免费的 API 服务。原生 API 会话不继承网页记忆；网页渠道可能受到站点账号记忆影响。首次接入宜在非敏感演示群中小范围确认。

## 语音朗读

群聊顶部的「自动朗读」开启后，只把后续新发布的 AI 正文加入播放队列。每条消息下方的喇叭按钮可「从这里向下朗读」，从选定消息读到当前末尾；若同时开启自动朗读，后续 AI 新消息会继续接入队列。悬浮控制窗可以暂停、继续、跳过整条消息或停止朗读。刷新页面或切换群聊会停止旧队列并关闭自动朗读，不会从第一条重播。

在顶部「朗读设置」中可为每位成员选择声音、语速、音量并试听。同一成员档案跨群复用偏好，设置仅保存在当前浏览器。默认只选本地声音；允许远程声音后，待朗读文字会交给浏览器对应的语音服务。代码、链接、表情图片、推理日志不朗读。不需要模型 API Key，也不增加聊天模型 Token 消耗。声音数量、质量及可用性取决于系统和浏览器；没有声音时请安装系统中文语音包并重启浏览器。

默认播放不影响讨论。自主群聊可勾选「等待此浏览器朗读完成」，暂停朗读期间也会继续等待；关闭等待或停止朗读即可解除。其他浏览器也开启等待时，所有等待都解除后才继续。关闭页面会尝试立即解除，意外断线最多 90 秒解除；已经发出的模型请求不会被这项开关取消。暂停讨论仍会收尾已开始的整组连发。

## 待命成员与单次 @ 任务

在「成员与设置」中关闭某成员的参与开关后，该成员仍在群内，显示「待命 · 仅回应人类 @」。此模式适用于自主群聊；普通消息、其他 AI 的 @ 和定时检查都不会自动唤醒它。输入 `@` 可以从包含待命成员的列表中选择目标。

即使全群讨论已暂停，人类发送 `@总结员 请总结刚才的分歧`，也会单独唤醒这位成员。它会读取当前群的公开上下文，用自己的身份完成一次任务，再回到待命；不会改变参与开关，也不会恢复全群讨论。可以先让扩展观点的成员单独回应，再点击「继续讨论」让自动参与的成员接续。正在思考的成员不会因重复 @ 再启动一个并行任务；如果收到新的人类内容，发言前仍需读到它。

单次回应包括该任务所需的阅读、思考和工具步骤，并非强制只有一次 API 请求；发布一次完整发言或明确等待后结束。它仍使用原群的调用、Token、金额预算和网站账户额度，不会自动重置限额。达到本场预算时需先调整或续开预算；可用「停止单次回应」取消任务。归档群、未配置的连接及未授权模型仍不可调用。
